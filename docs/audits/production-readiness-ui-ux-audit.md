## Executive summary

Arrival Atlas has a **strong spatial galaxy experience** on Life Events, Economic Reality, and Profile — especially with Journey Guide and cinematic unlock (arr-031). Underneath that, the product still behaves like a **beta prototype** in areas real users hit immediately:

- **Mock authentication** on the home page (`sessionStorage` flag, not real login)
- **No production language picker** (logic exists; UI only in unmounted `Header`)
- **Mobile navigation disappears** at ≤960px with no replacement
- **Split economic module routing** (`/modules/economic-reality` vs `/modules/financial-reality`)
- **No branded 404/500** — no `not-found.tsx` / `error.tsx`
- **Silent session recovery** — expired sessions recreated without telling the user

**Verdict:** Not ready for general public production without Critical and High fixes. Suitable for **controlled beta** with disclosed limitations after mobile nav and economic routing are unified.

**Overall score: 4.5 / 10**

No `middleware.ts`, no `redirect()` / `notFound()` in `apps/web/src`. No `loading.tsx`, `error.tsx`, or `not-found.tsx`.

### What works

- `AtlasHUD` links to 4 destinations for authenticated users
- Celestial transitions between destinations (`useAtlasNavigation`)
- Life Event deep links: `?mode=scenarios`, `?event={scenario}`
- Profile edit success: `?updated=1` → toast → param stripped on dismiss

### Critical navigation failures

| Issue | Impact |
|-------|--------|
| **`financial-reality` vs `economic-reality`** | HUD → galaxy ER page; profile CTAs → generic `financial-reality` form page |
| **Mobile nav hidden** | `max-width: 960px` — `.atlas-hud__nav { display: none }` — no hamburger |
| **Profile URL desync** | Galaxy selection on `/profile` does not push `/profile/{slug}` |
| **`?entry=CRISIS` ignored** | Generated by catalog; page never reads it |
| **No branded 404** | Invalid slugs show inline message without recovery |
| **Guest home** | No module discovery in HUD — direct URL only |
| **Home map nodes** | Click changes slide, does not navigate |

### Soft dead ends

- `/modules/[moduleId]` — “Module not found.” — no link home
- Invalid profile slug — message only, no back CTA
- 6+ API modules not in HUD — discoverability via in-content links only

### Orphan UI

- `Header.tsx` — drawer nav + language — **never mounted**
- `HomeSnapshotRenderer.tsx` — onboarding checklist — **not on any route**
- `ProfileMirrorOverview.tsx`, `ProfileDomainDetail.tsx` — superseded by galaxy

# 15. Final Report

## Critical Issues (must fix before release)

1. Mock authentication presented as real login/logout
2. Mobile navigation removed with no alternative (≤960px)
3. `financial-reality` vs `economic-reality` routing split
4. No production language picker
5. Silent session recovery on invalid/expired session
6. No `not-found.tsx` / branded error pages
7. Production-readiness gates open (skip link, mobile 375px, `lang`, beta disclosure)

## High Priority Issues

8. Profile galaxy URL desync  
9. `?entry=` ignored on Economic Reality  
10. Journey Guide welcome + LE intake stack  
11. Journey Guide English-only; static `html lang`  
12. LE intake — no success feedback  
13. ER empty state — no CTA  
14. Invalid slug/module — no recovery links  
15. `window.alert` for economic errors  
16. Logout doesn't clear API session or guide state  
17. Cinematic unlock — no skip  
18. Guest home — no module discovery path  

## Medium Priority Issues

19–30. Form validation gaps; SchemaForm remount data loss; dual session concepts; welcome not dismissible; modules outside HUD; inconsistent loading; theme toggle dead code; etc. (see session transcript for full list).

## Low Priority Polish

31–38. Orphan components; legacy discovery CSS; generic profile slide CTAs; FAB z-index; `aria-busy` on profile loading.

## Recommended path before public release

1. Work through [phase-1-release-blockers.md](../production-readiness/phase-1-release-blockers.md) (24 blockers + smoke gate)  
2. Manual smoke: mobile 375px, profile edit → home sync, ER empty/crisis paths  
3. Controlled beta with honest session/auth messaging
