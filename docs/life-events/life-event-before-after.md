# Life Event Module — Before & after

User-outcome comparison. No technical detail—only what someone experiences.

---

## New arrival

| Without Life Event Module | With Life Event Module |
|---------------------------|------------------------|
| Searches forums for “Anmeldung Berlin” and gets conflicting order-of-operations advice | Opens Atlas and sees **Complete Anmeldung** as the single critical focus |
| Opens five module pages unsure which applies | Plan groups registration, insurance, and banking in sequence with clear priority |
| Forgets insurance until a letter arrives | Insurance gap appears as an explicit blocker before it becomes a crisis |
| Gives up when overwhelmed | Progresses one step at a time with confidence level shown |

**Demo preset:** `new-arrival`

---

## Job loss

| Without Life Event Module | With Life Event Module |
|---------------------------|------------------------|
| Panics about rent and Krankenkasse with no ordered list | State shifts to **economic setup pending** with **high** severity |
| Does not know whether Jobcenter or Arbeitsagentur comes first | Focus: **Stabilize employment situation** with income and support steps linked |
| Avoids exploring benefits out of stigma or confusion | Scenario explorer previews support pathways without committing |
| Static checklist still says “update resume” as if nothing changed | Plan adapts when employment status changes |

**Demo preset:** `job-loss`

---

## Benefits discovery

| Without Life Event Module | With Life Event Module |
|---------------------------|------------------------|
| Assumes Wohngeld does not apply and never applies | **Benefits exploration** state surfaces relevant programs |
| Reads 40-page PDF guides in German legal language | Action breakdown explains application pathway in plain steps |
| Fears hidden obligations | Dedicated step: **Understand obligations and trade-offs** |
| Treats benefits as separate product area | Same plan connects housing, income, and support |

**Demo preset:** `benefits-discovery`

---

## Stable resident (bonus contrast)

| Without Life Event Module | With Life Event Module |
|---------------------------|------------------------|
| Product feels “done” after setup—no reason to return | **Situation stable** state invites periodic review and forward planning |
| Life changes (child, divorce, move) catch user off guard | Proactive timeline includes upcoming transitions |
| Uses Atlas only in emergencies | Retains value for long-term residents |

**Demo preset:** `stable-resident`
