# Architecture Decision Records (ADR)

Reserved for short, durable decision records using the format:

```text
Title
Context
Decision
Consequences
Status (proposed | accepted | superseded)
```

Formal specifications and long-form design docs belong in [../core/](../core/) and domain folders (e.g. [../platform/](../platform/), [../identity/](../identity/)) instead.

When adding an ADR, name it `NNNN-short-title.md` (e.g. `0001-profile-session-scope.md`).
